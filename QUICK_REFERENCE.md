# Quick Reference / Referință Rapidă

## ❓ Ce Situație Ai? / What's Your Situation?

### 🔵 Modificări deja pe GitHub (făcute de altcineva)
### 🔵 Changes already on GitHub (made by someone else)

**RO:** Ai văzut modificări pe GitHub.com → **PULL** (descarcă), NU commit!
**EN:** You see changes on GitHub.com → **PULL** (download), DON'T commit!

```
GitHub Desktop:
1. Click "Fetch origin"
2. Dacă apare "Pull origin", click pe el / If "Pull origin" appears, click it
3. ✅ Gata! Fișierele sunt acum pe PC-ul tău / Done! Files are now on your PC
```

### 🔴 AI făcut TU modificări în Greenfoot
### 🔴 YOU made changes in Greenfoot

**RO:** Ai editat și salvat fișiere → **COMMIT și PUSH**
**EN:** You edited and saved files → **COMMIT and PUSH**

```
Urmează pașii de mai jos / Follow steps below
```

## 🇷🇴 Pași Rapizi pentru Salvarea Modificărilor Tale

### 1️⃣ În Greenfoot Desktop
```
1. Editează codul
2. Apasă Ctrl+S (sau Cmd+S)
3. Testează cu Run
4. Salvează din nou (Ctrl+S)
```

### 2️⃣ În GitHub Desktop
```
1. Verifică fișierele modificate (panoul stâng)
2. Scrie mesaj de commit
3. Click "Commit to [branch-name]"
4. Click "Push origin"
```

### 3️⃣ Verificare
```
1. Du-te pe github.com/andrabel208/PiratesGame
2. Verifică că modificările sunt acolo
3. ✅ Modificările sunt în siguranță!
```

## 🇬🇧 Quick Steps for Saving Changes

### 1️⃣ In Greenfoot Desktop
```
1. Edit code
2. Press Ctrl+S (or Cmd+S)
3. Test with Run
4. Save again (Ctrl+S)
```

### 2️⃣ In GitHub Desktop
```
1. Check modified files (left panel)
2. Write commit message
3. Click "Commit to [branch-name]"
4. Click "Push origin"
```

### 3️⃣ Verification
```
1. Go to github.com/andrabel208/PiratesGame
2. Verify changes are there
3. ✅ Changes are safe!
```

## 🔴 Regula de Aur / Golden Rule

**Salvează → Commit → Push → Verifică**

**Save → Commit → Push → Verify**

Dacă ai urmat acești pași, modificările tale sunt în siguranță! 🎉

If you followed these steps, your changes are safe! 🎉
